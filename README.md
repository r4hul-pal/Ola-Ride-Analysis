# 🚖 Ola Ride Booking Analysis Dashboard

## 📌 Project Overview

This project analyzes Ola ride booking data to uncover business insights and operational trends.

The dashboard helps understand:
- Ride success and cancellation trends
- Revenue generation
- Vehicle-wise performance
- Customer behavior
- Driver performance
- Payment preferences

The analysis was performed on more than 100,000 ride records using SQL and Power BI.

## 🛠️ Tools & Technologies Used

- SQL (MySQL)
- Power BI
- Pandas
- Data Analysis
- Data Visualization
- DAX
- GitHub

 ## 📂 Dataset Information

The dataset contains 100K+ Ola ride booking records with details such as:

- Booking ID
- Ride Status
- Vehicle Type
- Pickup & Drop Location
- Ride Distance
- Booking Value
- Payment Method
- Driver Ratings
- Customer Ratings
- Cancellation Reasons

## 📈 Business Problems Solved

- Identified successful and cancelled rides
- Analyzed revenue generated from completed rides
- Found top customers by ride count
- Compared vehicle-wise ride distances
- Studied customer and driver rating trends
- Analyzed cancellation reasons
- Evaluated payment method usage

## 🧠 SQL Insights

Some important SQL analysis performed:

- Average ride distance by vehicle type
- Total revenue calculation
- Cancellation analysis
- Top 5 customers
- UPI payment analysis
- Vehicle rating analysis
- Incomplete ride tracking

## 📊 Dashboard Features

- Interactive filters

- Revenue analysis

- Ratings analysis
- Payment insights

## 🔥 Key Insights

- Prime Sedan generated higher booking revenue
- UPI was one of the most used payment methods
- Customer cancellations were higher during peak hours
- Certain vehicle types had better customer ratings
- Incomplete rides impacted operational efficiency
